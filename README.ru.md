# 🌐 Мини-переводчик

Лёгкий переводчик буфера обмена с глобальным хоткеем. Нажми хоткей после `Ctrl+C` — и сразу появится всплывающее окно с переводом.

[English](README.md) | **Русский**

---

## ✨ Возможности
- Глобальный хоткей: `Ctrl+Shift+Q` / `Ctrl+Alt+Q`
- Перевод содержимого буфера во всплывающем окне
- Автоопределение исходного языка
- 4 сервиса перевода с автофоллбэком:
  Google → Lingva → Lingva-зеркало → MyMemory
- Кнопка полной очистки буфера обмена
- 20 языков интерфейса
- Тёмная / светлая тема
- Автозапуск с Windows

---

## ✅ Требования
- Windows 10 или 11
- Интернет
- **Python 3.11 или новее** — нужен даже для `.exe` версии

## 🚀 Установка

### Шаг 1 — Установить / обновить Python (всегда, одна команда)

Открой **CMD** (`Win + R` → `cmd` → Enter):

```cmd
winget install --id Python.Python.3.12 -e --accept-source-agreements --accept-package-agreements & winget upgrade --id Python.Python.3.12 -e --accept-source-agreements --accept-package-agreements
```

Затем **закрой и снова открой CMD**, проверь:

```cmd
py -3 --version
```

### Шаг 2 — Обновить pip, setuptools, wheel (всегда, одна команда)

```cmd
py -3 -m pip install --upgrade pip setuptools wheel
```

## 📥 Установка приложения

### 🟢 A. Если у тебя `.exe` файл
Двойной клик по `MiniTranslator.exe`. Готово.

### 🟡 B. Если у тебя `.pyw` файл
```cmd
py -3 -m pip install --upgrade pystray Pillow
pythonw mini_translator_multilang.pyw
```

### 🔴 C. Если у тебя `.bat`, который собирает `.exe`
```cmd
py -3 -m pip install --upgrade pyinstaller pystray Pillow
```
Затем двойной клик по `.bat`. `.exe` появится в `dist\`.

## ▶️ Использование
1. Выдели текст в любой программе.
2. Нажми `Ctrl+C`.
3. Нажми `Ctrl+Shift+Q` (или `Ctrl+Alt+Q`) — появится окно с переводом.
4. Нажми **Копировать** или `Esc` для закрытия.

Можно также открыть главное окно и ввести текст вручную, затем нажать **Перевести**.

## 🛠 Проблемы

| Проблема | Решение |
|---|---|
| `'py' не является командой` | Переустанови Python с PrependPath (см. README погоды) |
| `pip` не найден | Используй `py -3 -m pip ...` |
| Хоткеи не работают | Их занял другой процесс. Используй кнопку **📋 Перевести буфер** в главном окне |
| Перевод не работает | Проверь интернет. Приложение пробует 4 сервиса подряд |
| Буфер пуст | Всегда сначала нажимай `Ctrl+C` — хоткей сам текст не копирует |
